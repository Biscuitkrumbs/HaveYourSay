# Have Your Say

A mobile-first internal feedback survey designed to be opened from a QR code.

## Current features

- Phone-only responsive layout
- 0–10 recommendation score
- Positive and constructive comments
- Team & Culture Plan feedback
- Team member recognition
- Store values:
  - Fun
  - Teamwork
  - Integrity
  - Recognition
  - Innovation
- Anonymous by default
- Optional follow-up details
